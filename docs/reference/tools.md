# Tools

> Generated by `scripts/gen-docs-reference` from each module's `ctx.tool` definitions and `module.json`. Do not edit this page: edit the code, then run `npm run docs:ref`.

263 tools across 23 modules. Every caller reaches a tool through the same path: Claude through MCP, a surface through HTTP, the CLI with `vyre call <tool> [json]`. The input is checked against the schema below, then the rules run, then the tool.

Callers are the kinds of caller that may use a tool: `cli` (the terminal), `local` (the Mac's own surfaces), `deck`, `capsule`, `mcp` (Claude and agents), `module` (another module). Any caller means the tool does not limit them. See [tools and events](../build/tools-and-events.md).

A tool marked "needs a person present" runs only after someone proves they are at the machine, with Touch ID, a passkey or the terminal: see [presence](../concepts/presence.md). A call from Claude alone cannot pass it.

## agents

### `agents.ask`

Talk to an agent: the text goes to its current thread (started if needed) and the reply comes back when the turn ends. If the thread stops on a permission question, returns with the question instead; the user answers it with threads.answer.

- Input:
  - `agent` string, required
  - `text` string, required
  - `surface` string
  - `wait` boolean
- Callers: any caller

### `agents.create`

Make an agent: a name, its projects ("*" for all), its credentials (Vault items for the setup token and an API key fallback, with a budget), instructions and model. kind "assistant" makes the one assistant, which sees every project.

## hands

### `hands.act`

Do one thing to one control, found by selector in a fresh observation: press it, set its value, focus it, type text into it, or send it a key. Then observe again and verify the effect. verified is true only when the re-observation shows it; the accessibility API accepting the action is not proof. Returns acted, verified, reason, before, after and changes.

- Input:
  - `kind` one of "press", "set", "focus", "type", "key", required
  - `selector` object, required: Copy it from an element of hands.observe. It is matched against a fresh observation, never used as a location.
    - `role` string, required
    - `container` string
    - `identifier` string
    - `name` string
    - `path` string
  - `app` string: App name or bundle id. Default: the frontmost app.
  - `key` string: For key: return, enter, tab, space, delete, forwarddelete, escape, home, end, pageup, pagedown, left, right, up, down.
  - `modifiers` list of one of "cmd", "shift", "option", "control"
  - `pid` integer: Process id; wins over app.
  - `settleMs` integer: How long to keep re-observing for the effect. Default 1500.
  - `value` string: For set and type.
  - `window` string: Only windows whose title contains this. Safer than relying on window order in a multi-window app.
- Callers: any caller

### `hands.observe`

Read the accessibility tree of the frontmost app (or a named app or pid): its window title, a bounded list of controls, each with a selector to hand to hands.act, its value, enabled and focus state and frame, and the text on screen. truncated says the list was capped.

- Input:
  - `app` string: App name or bundle id. Default: the frontmost app.
  - `limit` integer: Most controls to return, 1-500. Default 120.
  - `pid` integer: Process id; wins over app.
  - `window` string: Only windows whose title contains this. Safer than relying on window order in a multi-window app.
- Callers: any caller

## watchers

### `watchers.create`

Turn on a watcher exactly as it was last dry-run. Runs once now, then on its schedule. Only after the user has seen the dry run's items and agreed.

- Input:
  - `name` string, required
- Callers: any caller

### `watchers.hook`

A webhook call for a watcher whose schedule is webhook.

- Input:
  - `name` string, required
  - `body` any
  - `token` string
- Callers: its webhook route only, `POST /v1/<module>/<name>/hook`

### `watchers.items`

Items watchers have filed, newest first: for one watcher (name), one project (project slug), or all.

- Input:
  - `limit` integer
  - `name` string
  - `project` string
- Callers: any caller

### `watchers.list`

Every watcher: drafts Claude wrote, and those turned on, with state (draft, on, paused, changed, invalid), schedule, next and last run, and items filed. dir is the folder watchers are written in.

- Input: none
- Callers: any caller

### `watchers.logs`

A watcher's recent runs, newest first: when, why (schedule, retry, create, hook, test), items seen and filed, error and log lines.

- Input:
  - `name` string, required
  - `limit` integer
- Callers: any caller

### `watchers.pause`

Stop a watcher running until it is resumed.

- Input:
  - `name` string, required
- Callers: any caller

### `watchers.resume`

Resume a paused watcher, clearing its failure count.

- Input:
  - `name` string, required
- Callers: any caller

### `watchers.test`

Dry-run a watcher folder once, from since (default null), filing nothing. Returns the items it would emit and its logs, or what to fix. Required before watchers.create.

- Input:
  - `name` string, required
  - `since` any
- Callers: any caller
