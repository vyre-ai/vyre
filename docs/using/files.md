# Files

Files is one place in the sidebar. The list is All files, Recent, Your shared links and Shared with me, then groups for Projects and Agents.

Each agent has a folder. A Space has folders too. You can move or rename a file. An agent's folder can also be deleted on that agent's computer. Deleting a file that belongs to the Space is refused.

**Shared with me** lists files another person shared. You can read those. A file that is not shared tells you to ask the person who has it.

Word, Excel and PowerPoint open in the preview as a page of their text.

Earlier versions are listed, and you can restore one. If someone else is writing the same file, you wait up to 10 seconds and are then told who has it. The first writer's bytes stay.

A file an agent makes on its computer lands in that agent's folder and shows here. See [An agent's computer](agent-computer.md).

Publishing a site is not a place in the sidebar. It lives on a project's Site tab. See [Publish](publish.md).
