How it works
1One sheet, all five steps visible. Done steps keep their codes on screen, so a second phone or a missed scan never means going back.
2Tailscale is the recommended network: the only store download. The relay is the fallback, with a single-use code that lasts 10 min.
3The pairing code works only from inside the tailnet and only once. Typing it is the fallback when the camera cannot scan.
4Checks are the hero. Each proves one thing a user would otherwise find broken later: path, HTTPS, app mode, push, Face ID.
5Presence: pairing asks Touch ID once on the laptop, and that proof covers pairing for 10 min. Nothing else in the flow asks.
6vyre phone add prints the same steps. With --android --usb it installs the app over adb, no store and no browser.
