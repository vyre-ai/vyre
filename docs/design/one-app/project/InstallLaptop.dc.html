How it works
1One sheet, all five steps visible. Done steps keep their codes on screen, so a second phone or a missed scan never means going back.
2The relay QR is the primary path because it always works: single use, 10 min, sealed end to end, so the relay sees only ciphertext (ADR 0026).
3Tailscale is step 5, recommended and optional. Tailscale #19147 (iOS DNS override) and the tunnel drops in #18889 and #19504 rule it out as the only path.
4Checks are the hero. Each proves one thing a user would otherwise find broken later: path, HTTPS, app mode, push, Face ID. The Tailscale check appears only when it is reachable.
5Presence: pairing asks Touch ID once on the laptop, and that proof covers pairing for 10 min. Nothing else in the flow asks.
6vyre phone add prints the same five steps in the same order. With --android --usb it installs the APK over adb.
7Smooth: checks stream in and turn lime in place with no layout jump. The relay to Tailscale switch happens mid-session (resilience R5): no reload, no prompt, only the path line changes.
