How it works
1Three commands on the Mac and never a shell on the server. vyre box add installs over SSH, opens the one-time link through a tunnel, and says "Finish in your browser. I'll wait here."
2One screen per step: one line of purpose, one primary, Skip as the secondary. Skipped steps wait in Settings under Finish setup. The link is single use and expires in 1 hour.
3Claude Code: the subscription through claude setup-token (sign in, paste the code) or an API key, straight into the vault. The Mac's own sign-in is never read. Codex is optional, later.
4Your address is the one step Tailscale forces. HTTPS off shows Turn on HTTPS and Check again, and says once that certificate names are public. When it passes, the page moves to the box's own address.
5The ending is one screen: juno's greeting streams, three ticks, one button. Open Vyre makes the first passkey with Touch ID; after that, proof is asked only to pair, release a secret or send.
6Devices hands off to Add your phone (Install board) and the Capsule. The phone opens on Now with the test notification answered and a one-time swipe hint on a demo row.
7Smooth: each step saves as it is answered, so a closed tab (or vyre box add run again) resumes where it stood. Browser and terminal read the same onboard.status, so a tick in one is a line in the other. History imports in the background and never blocks Open Vyre.
