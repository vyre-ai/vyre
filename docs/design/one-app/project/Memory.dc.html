How it works
1A memory is one fact in plain words, with its source and date on the row. Anything Vyre tells you comes with a source: the session turn, the email or the call note, one click away.
2Facts live per project or about you. A project's facts reach only that project's sessions; "Where it is used" names them, so nothing leaks from Harlow Legal to Northwind Bakery.
3Every line of a fact edits in place and says Saved where you typed, with Undo. Changing memory needs presence; one Face ID covers 30 min and the line says so.
4Lessons are proposed by agents and never apply unseen. Accept is the one primary; Edit and Retire sit beside it. The same row shows in Needs you, so the count joins the Now badge.
5Forget is a Hold button whose label carries the count (Forget 3 memories). Stale and disputed facts say so on the row, which is where forgetting usually starts.
6Phone: Memory opens from the Places sheet as a pushed page. Lessons to review sit on top, then facts by project, each with its source.
7Smooth: the list paints from cache and is virtualized past 100 rows. Search filters the cached facts in the same frame you type. Saves and forgets go through the outbox: forgotten rows collapse on release, with a 4 s Undo.
