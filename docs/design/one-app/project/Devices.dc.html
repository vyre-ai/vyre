Pairing asks for Face ID once. Remove sits on each device's page and takes a hold.

How it works
1Every row answers three questions: how it reaches the box (Tailscale direct, or the relay with its city and latency), when it was last seen, and which keys it holds.
2A lime dot is a direct path; a grey dot is relayed. The relay is listed as a device so you can see what it holds: nothing.
3Remove is a Hold button that names the device. Removal is immediate: the presence key dies and sessions end. No undo, only re-pairing.
4Network reads Tailscale and never writes to it. Exit node and Funnel come as steps you run, with Copy steps.
5VyreDrive shares are read-only until you allow writes per share, mounted at ~/Vyre/Box/<share>. Taildrop sends with vyre send <file>.
6The phone's list is a pushed Settings screen. This phone sits on top with its own path, so "why is it slow" has an answer.
