A violet dot means a thread in that project waits on you. Tap a project for its threads, rules and memory.
How it works
1A project is a folder on the box, a folder on the Mac seen read-only, or no folder at all (Personal). One file, .vyre/project.json, declares it; the file is the truth and the list only caches it.
2Threads join by folder or by pick. Vyre never sorts them on its own. Status marks match Chat: violet dot waits on you, lime ring runs, filled dot unread, hollow dot done.
3"Always in Harlow Legal" collects every ask answered with that button. Remove takes effect at the next tool call. Rules never cross into another project.
4Defaults set the provider and mode a new session starts with: Plan first, Asks first or Edits allowed. There is no no-asks mode; Always answers build this project's allow list.
5Memory here reaches only this project's briefs, so Harlow and Northwind stay apart. Files come through VyreDrive's projects share, read-only on the Mac.
6Phone: Projects opens from the Places sheet as a pushed page, back to Now. New project is the last row; the name and folder come next.
7Smooth: the list paints from cache before the box answers. Remove goes through the outbox: the rule collapses to "Removed" in place with a 4 s Undo, and no row below it jumps.
