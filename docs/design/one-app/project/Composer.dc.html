How it works
1Same keys as Claude Code in the terminal. The phone gets them as taps: long-press send to queue, the mode chip for ⇧Tab, a Stop button for Esc.
2Steer is the default while kit works: SDK priority "next". Queue for after is Vyre's queue, so it can be edited or taken back until the turn ends.
3Rewind to here cuts this same thread back to before that message; no fork. Its text comes back to edit. Also undo file changes (rewindFiles, needs File checkpoints) makes it a hold.
4The line's first character picks the mode and the composer names it: Shell, Memory. Esc leaves it.
5Smooth: menus filter locally from a cached index, so / and @ answer on the next frame. Steer and memory saves are optimistic: "steering" and "Saved" draw on send and confirm in place.
