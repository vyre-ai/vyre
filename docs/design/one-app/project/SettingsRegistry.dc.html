How it works
1One registry, 61 settings, 11 groups. A 320 list with search on top and the detail capped at 720. Each group row says its current values, so most visits end in the list.
2Scope sits at the top of the detail: Account | Project, with the project picker joined to Project. Project shows only the 20 settings a project can override; the other six groups say "Account only" and link to your account.
3A source chip only when the value is not the default: Project beats Account beats default. A "Claude Code file" value comes from the repo's committed file: read-only, the path on hover, Open file.
4Reset is a ghost button that names where it goes: "Reset to Account (Asks first)". Hover or focus on the desktop, always on touch. No confirm; Undo for 4 s. A whole group is a Hold button with the count.
5Applies now is not printed. "Next session" gets a clock and "After restart" a refresh; restart changes from any group collect in one banner with Restart now.
6Under 720 the group list is a page and a group pushes in with the scope switch on top. Controls are 44 tall and the reset line is always shown.
7Smooth: settings.set is optimistic. The row changes on tap; if the box refuses it flips back with a "Not saved" line and the failed glyph. Saved, Reset and Undo share one reserved slot, so nothing moves when one appears. Search filters in memory in one frame.
