The default path, per platform
1iPhone: the web app over Tailscale. No Apple account, push works, and Tailscale is the only store download.
2iPhone without Tailscale: the same web app over the relay. One extra hop, sealed end to end, nothing to install first.
3The free Apple ID build stays behind Advanced. It expires every 7 days and has no push, so it is never the default.
4Android: the APK over adb from the laptop (vyre phone add --android --usb). Full native and exempt from developer verification.
5Android with no computer at hand: Install app in Chrome. The APK from the box is offered, with the verification wait stated up front.
6Every path pairs with one Touch ID on the laptop and saves a Face ID or fingerprint key on the phone. Nothing else asks.
