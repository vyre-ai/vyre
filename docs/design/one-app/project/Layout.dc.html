Layout · one breakpoint for shape, two for extra panes

Under 720 the app is pages you swipe. From 720 it is a rail with list and detail. Wider screens only add panes.

Layout reads the window's width, never the platform. A phone in landscape, an iPad and a narrow desktop window get the same rules. The composer and cards also check their own container, so they fit inside a split pane.
