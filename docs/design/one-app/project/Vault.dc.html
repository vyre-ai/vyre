How it works
1Typed kinds: Login, Passkey, Authenticator, API key, SSH key, Card, Note, .env file. The list groups by kind; chips filter.
2The lock pill is the whole unlock model: one Face ID or Touch ID opens 30 min, use does not extend it, and locking the device closes it. Locked, it reads "Locked · Face ID to open".
3Reveal shows the value in a sheet that hides itself after a few seconds. Copy uses an expiring clipboard and says when it clears.
4Codes show the current value large and the next one small, so a code about to roll over is never a guess. The ring counts down the 30 s window.
5Autofill goes through each system's own autofill. Chrome gets the only picker Vyre draws. The log names the surface: ios, android, mac, chrome, capsule or computer.
6Import previews before it writes: add, same, conflicts (skipped by default), renamed and skipped with reasons. Codes come in from a Google Authenticator export QR. Reused passwords become one Planner todo.
