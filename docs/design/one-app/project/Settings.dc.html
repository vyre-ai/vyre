How it works
1Nine sections, one list. Each row says its current value (Dark, 5 of 6 kinds, Touch ID, Claude), so most visits end without opening a detail.
2No Save button. A change applies on the frame you make it; "Saved" appears in place for 2 s. If the box refuses, the control flips back and the line reads "Not saved" with the failed glyph.
3Notifications per kind: asks, drafts, questions, watch, lessons, planner. Turning one off stops the push, never the row in Needs you. Quiet hours hold pushes; alarms and timers ring through.
4Presence lists what asks for proof (pairing, vault secrets, send, post, pay and delete outside) and one key per device. One proof lasts 30 min. Sessions: Claude or Codex by default, subscription, setup token or API key, "Switch to API key at the limit", idle close 10 min, 6 live.
5Attention colour is a two-swatch choice, violet or teal, shown as the dot it will colour. Network shows Glass hand-back (Off, 2, 5 or 15 min) and opens Devices for the links rather than repeating them.
6Smooth: toggles are optimistic through the outbox, so offline changes queue and replay. Settings paint from cache under 1 s; the phone list is one inner scroller with the header fixed, and a toggle shows "Saved" in place of a haptic.
