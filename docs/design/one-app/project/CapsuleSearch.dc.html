How it works
1Speed: local results paint under 50 ms after each keystroke, from the index on this Mac (sessions, agents, projects, files, apps, commands). Nothing waits on the network before they show. No spinner wall, ever.
2The panel: 680 wide, radius 14, panel fill, 1 px rule-strong, the float shadow, opaque. Input 56 (mark 20, field 15/22), group header 28, row 44 (tile or icon 24, title 13, meta 12), footer 32. It grows to 560, then the results scroll inside.
3Groups keep one order: Needs you, Sessions, Agents, Projects, Files, Apps, Commands. The first row is selected at once; the matched part is 600. Violet is only the Needs dot, label and the mark's dot.
4Keys: ↑↓ move, ⏎ opens the selected result (or copies, for a code), ⌘O opens it in Vyre, Esc clears, a second Esc hides. The footer holds only these hints, never a status line.
5An exact command match answers in its own row: the code, the next code and the ring. Touch ID releases the secret once and covers secrets for 30 min, so ⏎ copies with no prompt.
6Single words and exact matches never start a Vyre IQ answer; they stay plain search (see "Capsule · Vyre IQ answers"). The mic and the "@kit" chip sit at the input's right only when set or installed.
7Follows the system appearance: dark here, paper on the -paper board, the same tokens. Mono only for commands, paths and codes.
8Smooth: one paint per keystroke, no skeleton for local rows. Rows keep their slots as you type and groups shrink from the bottom, so the selection never jumps. The panel height eases once (150 ms) and never while a key repeats.
