How it works
1When it answers: a question-like input (several words, a question word or mark) starts a quick answer on the fast model about 600 ms after typing pauses. A single word or an exact app, file or command match never does. More typing cancels it; it restarts after the next pause.
2The card sits at the top, above the local results. Label "Vyre IQ", with "quick" or "deeper" in meta. There are no "Quick answer", "Deeper answer" or "Follow up" rows.
3After an answer the field reads "Ask a follow-up": ⏎ continues the thread, ⌘⏎ re-asks on the deeper model with thinking, ⌘O opens the thread in Vyre (Chat).
4Esc clears back to plain search; a second Esc hides the panel. The thread is kept in Vyre.
5Sources: up to 3 chips, then "+2 more". A chip or ⌘1..⌘3 opens that session in Vyre at the turn the answer came from. A memory chip opens the fact in Memory.
6(proposed) until memory-iq confirms: the confidence field behind "Not sure" and every source field (session title, project, when, turn).
7Honest states: "Not sure" shows what it found and makes no guess. Nothing found says so and offers ⌘⏎ Think deeper.
8Smooth: the answer streams paced to the display, so the prose never reflows in bursts. The card grows downward and the input never moves. The local results collapse to one line once, on the first words, and never jump again.
