# Chip token

28 high, radius 14, fill `--hover` (or an accent, warn or error wash), a 14 icon or a mark, a caption label and, with `onRemove`, a 24 x that removes it. With `onPress` the whole chip
opens its picker. Used above the composer's box for attachments, mentions and the one or two states that differ from the default. A state at its default shows nothing.
