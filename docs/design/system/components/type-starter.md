# Type starter

A flush card of selectable Rows (Blank, Kit starters such as Assets and Beneficiaries, a Kit chip on those), then "It starts with 6 fields" with the field names as chips, then the Name field and the Holds work switch. The list of starters comes from the installed Kits; Blank is always first.
