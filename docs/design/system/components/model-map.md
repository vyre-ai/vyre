# Model map

The first screen of Customize for Records. One Row per type: face, plural name, "6 fields, 0 assets", a Kit chip when it came from a Kit. Under a row, a line of link chips ("Links to  Clients (Client)", "many Assets (Asset)") so the shape of the firm's data is visible without opening a type. A press opens the type. "Add a type" sits below the card.
