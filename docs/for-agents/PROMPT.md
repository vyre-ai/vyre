# The prompt to give your AI agent

Copy the text below into ChatGPT, Claude or any agent that can read links.

```text
Read https://vyre.run/agenthome.md and follow it to show me how my business would run on Vyre. Ask me what you need.
```

The prompt is short on purpose. The instructions live on one page for agents, [Start here, for AI agents](START-HERE.md), which is served at <https://vyre.run/agenthome.md> and, as readable HTML, at <https://vyre.run/agenthome/>. It tells the agent what Vyre is, where every page and doc is, what to ask you, how to map your business as an AI-native version of itself, and how to help set Vyre up today. The method behind the mapping is [Map your business onto Vyre](MAP-YOUR-BUSINESS.md).

[vyre.run/map](https://vyre.run/map/) has a short form that adds your industry, team, roles, records and tools to the prompt on one line before you copy it. Nothing you pick there leaves the page.
