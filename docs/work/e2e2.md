## Scope

The matrix every 0.2 "done" is proven on, on GitHub-hosted runners only (never testbox, which is
the user's real server, and never the user's Mac session). Targets: Linux servers (x64, arm64),
Windows 11 (in Docker on a Linux runner), Android (emulator), iOS (simulator), macOS. Mac lanes
that need real hardware run in the `vyretest` user on the user's Mac once it exists. Automated AI
tests use cheap pay-per-use API keys stored as GitHub secrets, never the user's own accounts.

## How a device reaches the box

The loopback onboarding refuses any Host but 127.0.0.1 (DNS rebinding), so every device reaches
the box as 127.0.0.1:7300:
- Linux Chrome: on the box's own runner.
- Android emulator: `adb reverse tcp:7300 tcp:7300`.
- Windows 11 guest: `netsh interface portproxy` inside the guest, to a relay on the runner.
- Mac and the iOS simulator (another runner): a throwaway tunnel from the box's runner, sent
  with Host 127.0.0.1:7300, and a local proxy on the Mac's 127.0.0.1:7300.
