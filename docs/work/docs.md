# docs

Branch: work/docs · Worktree: ../vyre-docs · Owner session: docs · ADR 0019

## Scope

docs.vyre.run: one wiki of every Vyre doc, as `.md` files that people and agents both read.
Owns `docs/` (except `docs/work/`, `docs/proposals/`, `docs/design/boards/`, which stay internal and
unpublished), `scripts/build-docs`, `scripts/docs-check`, `scripts/gen-docs-reference`, and the
`vyre-docs` Cloudflare Pages project. Small change by contract in `site/` (a Docs link).

## The contract every page follows

- The tree is organised for readers. `docs/nav.json` lists every published page, in order.
  A page not in the nav fails `docs-check`.
- Front matter on every page: `title`, `summary`, `audience`, `owner`, `status`. See
  `docs/CONTRIBUTING-DOCS.md` for the template and style rules.
- A moved page leaves a stub with `redirect: <new path>`; the build turns it into a 301.
- Reference pages under `docs/reference/` are generated by `scripts/gen-docs-reference` from the
  code (module.json, `ctx.tool` descriptions, `vyre help`, config defaults). Edit the code, not
  the page. `docs-check` fails when they are stale.
- Every feature merges with its doc page.
