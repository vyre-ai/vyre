Run Claude Code on your own server.

Sessions you start in Vyre run on the server, so they keep going after you close your laptop. Vyre also reads every Claude Code session you run. Next month, ask what you decided about the Harlow contract and you get the answer, with the session it came from.

$ curl -fsSL https://vyre.run/install.sh | sh

Run this on your Linux server. It needs Docker, and it asks before installing it. Vyre goes in /srv/vyre, and the installer prints a link. You finish setup in your browser.

$npm install -g https://vyre.run/box/vyre.tgz
$vyre up

This connects your Mac to your Vyre server over Tailscale, so set up the server first. A Mac-only setup is coming. Vyre isn't on npm yet, so you install it from the same file the server uses.

  • MacNode 22.5 or newer
  • Linux serverDocker Compose 2.24 or newer

01Capsule · on your Mac

Press ⌥Space in any app and type what you need.

The Capsule is a small bar that opens on top of whatever you have open, a call or a doc. Type a question and your assistant answers it. Start with @kit and the message goes to the agent named kit instead. Esc closes it.

⌥Space
Opens the Capsule in any app on your Mac. You can switch it to Control pressed twice.
@ a name
Type @ and an agent or project name to send it there instead of to your assistant.
Who gets it
The Capsule shows who will get your message before you press Enter.
Old answers
If you covered it in an earlier session, you get that answer and a link to the session.
Voice
Talk instead of typing. Deepgram turns your speech into text.
do …
Start a message with “do” and Vyre uses your Mac's mouse and keyboard for you. It asks before it sends anything.

06Make it yours

Open source. Switch off the parts you don't use.

Vyre is a Claude Code plugin and a small daemon. The Capsule, Glass, memory and the vault are separate modules, each with its own switch in Settings. They talk to each other through the same API you can call from your own code.

One settings page
All the settings sit on one page in the Deck.
Modules
Turn a module off and the rest keep working.
Build your own
vyre module new gives you a starter module to edit and test.
Updates
vyre update installs the latest release. vyre update --rollback puts back the version you had.
Apache 2.0
You can change the code and run your own version.

07Safety rules

Rules Vyre keeps whatever your settings say.

Vyre checks these in code that runs outside Claude, so a prompt can't turn them off. Some still have gaps, and the security doc lists them.

  1. An email or post waits for you to approve the final text before Vyre sends it as you.
  2. You see who a message goes to before it goes.
  3. Every file Claude writes or edits goes on a list you can check.
  4. An answer from your sessions links to the turn it came from.
  5. Agents, logs and notifications never see a vault password.
  6. The Capsule still finds apps and files on your Mac with no network.

FAQ

Common questions

Is it free?

Yes. Vyre is open source under Apache 2.0. Your agents run on your own Claude plan or Anthropic API key, so you pay for that and for your server.

Where does my data live?

On your server and your Mac. vyre.run hosts this page and the installer. Your sessions, memory and vault never go through it.

Do I need a server?

Yes, for now. Vyre needs a Linux server with Docker, like a small cloud server or a spare PC at home. Your Mac connects to it. A setup that runs on one Mac, with no server, is coming.

Does it replace Claude Code?

No. Vyre is a Claude Code plugin with a small daemon next to it. You keep using Claude Code the way you do now, and Vyre adds memory, the vault, agents and the Capsule.

What is Tailscale for?

Tailscale puts your server, Mac and phone on one private network. Only devices on that network can open your Deck. Tailscale already knows it's you, so Vyre has no separate login. The free plan is enough.

Is it ready?

It's version 0.1, so expect bugs. Everything on this page works today except the items marked coming. Please report problems on GitHub.

Does it run on Windows?

Not yet. The server runs on Linux and the Capsule runs on macOS. You can open the Deck in any browser on your Tailscale network, Windows included.
