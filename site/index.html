Open source · Apache 2.0 · A Claude Code plugin

Claude Code on a machine you own.

Vyre adds what Claude Code leaves out: projects, memory, agents, a vault, and a private address that only your devices can reach. It plugs in the way any plugin does, so each time Claude Code gets better, Vyre does too.

Assistant and agents

One assistant sees every session you run.

You get an assistant at setup. It sees every project and every session, and it can start, drive, watch and stop any of them. Make other agents when you need them, a researcher or a bookkeeper. Each runs headless on your own Claude subscription, reads only the projects you give it, and can have its own computer.

Projects

Type vyre in any terminal. Your work is there.

A project is a folder with its threads and watchers, and its own context graph. The project graphs feed one main graph, which only your assistant and the agents you grant can read. Nothing from one client's project reaches another's.

The home lists every project, a new session without a project, and every agent. It works the same over SSH.

Learning

Correct it once. A hook enforces it from then on.

Your corrections, the edits you make to a draft and the tool calls you deny become lessons. Vyre checks each lesson in a hook, so the model can't forget it. A reply that breaks one goes back to Claude before it reaches you. Break a lesson again and it moves up: remind, then ask, then block.

Vault

One vault for your passwords and your agents' keys.

Keep logins with one-time codes, cards, secure notes, API keys and env sets, with autofill in the browser and on your phone. Import from 1Password, Bitwarden, Chrome or Safari. Agents use a credential without seeing it.

Share one item as a pass, and revoke it in one step. When a teammate leaves, one action ends every pass they hold and lists what to rotate, so nobody walks away with your env file.

Security floor

Nine rules no setting can switch off.

Vyre enforces them outside the model, in the Rules hook and the Gate. Section 11 of the spec has the full text.

  1. Nothing goes out as you until you've seen the final words.
  2. You see where something is going before it goes.
  3. A thread is one thing wherever you view it.
  4. One screen types into a thread at a time.
  5. Every file change shows, including ones a command made without saying so.
  6. Only an explicit question from an agent asks for your attention.
  7. Vyre can show the source of anything it tells you.
  8. No Vault value appears on any screen, log or event.
  9. The Capsule works offline on your own Mac.
