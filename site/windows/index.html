Vyre / Windows

Vyre on Windows

Vyre, in your Windows tray.

A tray icon and an Alt+Space panel, connected to your Vyre server. Pair a PC with 13 words or a QR code from your other device.

Set up VyreRead the steps
What you get

The same window, on your PC.

  • A tray appA Vyre icon in your tray, and an Alt+Space panel to ask from.
  • Pair with 13 words or a QR codeType the words or scan the code from your other device, then confirm the server’s address and key fingerprint.
  • Your shared folder as a driveThe tray’s “Open Vyre Drive” maps a folder your server shares as a drive letter.
  • Signed updatesThe app updates itself, only from releases the Vyre key signed, and never to an older version.
Install

Install the app, then pair your PC.

Set up your server first, from the Vyre app (see Get started).

  1. Download the installer. VyreSetup.exe comes with each release on GitHub. The installer script checks its SHA-256.
  2. Run it. The app is not code-signed yet, so Windows asks you to choose “More info”, then “Run anyway”.
  3. Pair your PC. In Settings on your other device, add a Windows PC, then type the 13 words or scan the QR code on the PC.
  4. Press Alt+Space. Ask from anywhere, or open the tray icon.
What it needs
PCWindows 11
ServerA Linux server, or a Mac that stays on
AIOne of Claude, Codex, Grok or OpenRouter

What to expect in 0.5.0

  • The app is not code-signed yet, so Windows asks you to confirm on the first run. The installer script checks the file's SHA-256, and updates install only when the Vyre release key signed them.
  • A Windows PC is a device: it joins a team or connects to a server that runs on Linux or on a Mac that stays on.
  • Mapping the drive for files over 50 MB needs a registry change by an administrator.

Coming next

  • Code signing for the Windows app.
Questions

Questions about Vyre on Windows.

Can my Windows PC be the server?

Not yet. The server runs on Linux or on a Mac that stays on, and your Windows PC joins a team or connects to that server.

Why does Windows warn me?

The app is not code-signed yet. The installer script checks its SHA-256, and updates install only when the Vyre release key signed them.

How do I pair a PC?

In Settings on a device you already use, add a Windows PC. Type the 13 words or scan the QR code on the PC, then confirm the server’s address and fingerprint.

Is there an Alt+Space conflict?

The panel opens with Alt+Space. If another app uses that key, change one of them in its settings.
