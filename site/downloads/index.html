Check what you download

Every file is signed.

The release lists each file and its checksum, and signs that list with a key the Vyre app and the install line already know.

  • SHA256SUMSThe checksum of every file in the release. Download SHA256SUMS
  • SHA256SUMS.sigAn Ed25519 signature over that list, by the release key. Download SHA256SUMS.sig
  • The release pageRelease notes, every file and how to check them. Open the latest release
Questions

Questions about downloads.

Do the links always give the newest version?

Yes. Each button points at GitHub’s latest release, so it serves the newest file and the version on this page moves with each release.

Is there a Windows file besides the installer?

The PowerShell line and VyreSetup.exe do the same thing. The installer file is the one to double-click; the line is for a terminal.

Why is there no app store link?

The phone apps are not on a store yet. Android installs from a file you open on the phone. iPhone is built and installed with Xcode.

How do I know a file is what the release signed?

Every file is listed in SHA256SUMS, and SHA256SUMS.sig is an Ed25519 signature over that list by the release key. The Vyre app and the install line check it for you; to check it yourself, read the release page.
