Put the server on a machine you own.

Linux server

A Linux machine you can reach with sudo. Run the line as yourself, not as root. The installer asks before it adds anything.

$curl -fsSL vyre.run/i | sh

Read the Linux server page

A Mac that stays on

Run this line in Terminal on that Mac. It asks for the Mac's password once so Vyre can start when the Mac starts.

$curl -fsSL vyre.run/box/install-mac-server.sh | sh

Read the Mac page

Signatures

Each release is signed with the Vyre release key, and the app and the server install check that signature before they update. The signature files and the full list of files for this version are on the release page.
