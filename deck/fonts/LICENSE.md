# Fonts

Served from the box itself, so the Deck never waits on a third party to draw text, and draws it
the same with no internet at all. Latin subsets, variable weight, as Google Fonts publishes them.

- Instrument Sans (400 to 600), by Rodrigo Fuenzalida and Jordan Egstad. SIL Open Font License 1.1.
- JetBrains Mono (400 to 500), by JetBrains. SIL Open Font License 1.1.
