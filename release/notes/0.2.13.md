Vyre 0.2.13 fixes what the first real installs of 0.2.12 found, and closes a security gap. Install this one rather than 0.2.12.

## Security

- A module you add yourself can no longer reach another machine: only Vyre's own modules may. Modules you add can never use the tools that pair, admit or drop a device or set a server up, whatever their manifest asks for, and Vyre refuses such a module when you add it.

## Fixes

- Something an assistant asked to send, that you approved on your phone, now goes out when it is sent again. Before, every approved send was refused.
- The install line from the Vyre app ends after the four words. It no longer goes on to show an old pairing code and wait five minutes.
- The installer waits up to three minutes for the four words on a first start, and says it is waiting.
- A vyre command that needs Docker, run without sudo, tells you to run it with sudo instead of showing Docker's error.

## Setting up

1. Reserve your name at vyre.run/setup. You get a code.
2. Install the Vyre app on your Mac or Windows PC from the downloads below, then paste the code.
3. Join a team, or Add a server: choose With Records (recommended) or Without Records, run the one line the app shows on the server, and confirm the four words in the app.
4. Add your phone from the app.

## Updating

A server updates from Settings, Updates, or with `sudo vyre update`. Your data, vault and sign-ins stay as they are.
