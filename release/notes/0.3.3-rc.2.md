Vyre 0.3.3-rc.2 is a release candidate on the beta channel, for testing before 0.3.3. Do not put a team on it yet: the items under Known issues are open.

## What to test

- A team in one Space: the owner makes the team in the app and it is the server's own Space. Members join, share Records, and each has their own chats.
- A shared chat with three people: each person's message runs on that person's own AI sign-in, messages sent while a turn is running wait their turn and are all answered, and nobody's turn uses another person's sign-in.
- A person's own session on their own computer, handed to the server and taken back.
- Updating from 0.3.1 with `vyre update` as a normal user keeps you signed in.

## Fixed since 0.3.3-rc.1

- A member's turn can no longer run on another person's AI sign-in by attaching a picture or by mentioning a provider without an account.
- Messages queued behind a running turn in a shared chat are all answered, in order, each under its own person. A message that cannot run says so in the chat.
- A person's skills are loaded for that person's turn, never the chat starter's or the owner's.
- "Set up My Cloud" on a server whose Space is a team's is refused with a next step: connect another server.
- With about nine sessions at once the server no longer stalls.
- Lumen on a Mac no longer quits when the server sends an ordinary nested event, and refuses one nested past 64 levels.
- The first Records write to a new kind of record no longer waits minutes.
- The product is called Lumen in the words a person reads.

## Known issues

- First install with Records: 13 to 29 minutes from Records being up until every module's record types exist. Until then the app says it is waiting for the records, and a first chat can take about 20 seconds.
- A person removed from a chat is cut off from its live activity at the next call anyone makes into that chat, not at the instant of removal.
- A second Space on one server can still be made by resuming a creation begun before this version, and exists on servers that made one earlier. Those keep working.
- On a server, an assistant with no AI sign-in picked for it runs on the server's own sign-in for the owner's requests. A member's request to such an assistant is refused.
- The command is still `vyre capsule`; a `vyre lumen` name comes later.

## Updating

This release is on the beta channel only. A server on the stable channel stays on 0.3.1.
