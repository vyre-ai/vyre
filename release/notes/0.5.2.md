Vyre 0.5.2 fixes pairing a new server from the Mac app.

## Fixed

- You can pair a new server from the Mac app. Before, you typed the server's code into the app and the app's code back at the server, the server said the codes matched, and then the app said "Something went wrong." and the server never became yours. The app changed the key it reaches your servers with on almost every connection, so the server did not recognise the app when it came back to finish.
- The Mac app keeps that key in your Mac's Keychain, so it is the same key after you quit and reopen the app, and the server still knows it. The key never leaves the app's own code: the web page inside the app cannot read it.
- The Mac and Windows apps now sign the last step of pairing, the proof that makes the server yours. They only sign a message of exactly that form and say "Make the server you are pairing yours" when they ask you.
- When pairing a server does not finish, the app says why, for example "Your server stopped answering before the pairing finished, so it is not yours yet", instead of "Something went wrong."

## Updating

The Mac app: download the new dmg from the release and replace the app. Then run `vyre space up` on your server for a fresh code and type it in the app.

A Linux server does not need an update for this fix. You can still update it from Settings, or with `vyre update`.
