Vyre 0.6.4 makes your server quick again, fixes sending in chat, and adds OpenCode.

## Fixed

- A server could grow slow and run hot. Vyre opened a new connection to watch its computers every few seconds and never closed the old ones. It now keeps one, and waits longer between tries when the connection is refused.
- Records could take about 9 seconds to load on a server with a lot of history. Vyre now remembers what it has already checked, so lists open at once.
- Sending a message in a chat failed with "This chat has not started yet". Every message now sends.
- A device that lost its chat key can replace it from Settings without another device.
- The Engineer no longer shows twice in the chat list.

## New

- OpenCode: add one OpenCode key in Settings > AI accounts, with a switch to use only OpenCode Go models.
- Teammates keep a stable id and are made the first time you ask for one.
