Vyre 0.3.3-rc.4 is a release candidate on the beta channel, for testing before 0.3.3. This page is a stub: the list of fixes is written when the candidate is cut.

## Known issues

- Project folders on a team server: renaming a project changes its short name, which keys its group. The next launch in a renamed project is refused with words naming the old name, and nothing is opened by mistake. A re-key step for a renamed project is planned.
