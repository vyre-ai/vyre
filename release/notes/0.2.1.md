Vyre 0.2.1 fixes Claude sign-in on a new server and lets the phone app be added to your home screen.

## Fixed

- Signing in to Claude from Vyre now accepts the code you paste from the Claude page, including the form that ends in a `#` and more text. Before, that paste was rejected.
- The phone app at app.vyre.run now has a web app manifest, icons and iPhone tags, so Add to Home Screen installs it as an app.

## Updating

A Linux server updates from Settings, or with `vyre update`. The stable channel takes this release. Your data, vault and sign-ins stay as they are.
