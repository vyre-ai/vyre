Vyre 0.5.1 fixes first-time setup and makes Vyre steadier.

## Fixed

- A new person on a device with no server is taken to add a server before the vault, and is told so plainly ("Vyre keeps your vault on a server, and this device has none yet. Add a server first."). A device that stopped at the vault picks up again at the server step.
- Vyre uses less memory when it starts and once it has settled.
- A vault wipe no longer refuses because a sealing process is starting or exiting.
- The docs show code examples correctly: an address such as `alex@192.0.2.10` in a command no longer turns into "[email protected]".
- The steps an AI agent follows on vyre.run/agenthome ask for your yes before creating a server, and the agent removes its own access afterwards.

## Updating

A Linux server updates from Settings, or with `vyre update`. The Mac app updates itself.

0.6 and 0.7 (see the roadmap).

The fixes 0.5.0 listed as planned now land in 0.6.
