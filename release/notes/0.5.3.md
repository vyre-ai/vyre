Vyre 0.5.3 is the same first run on the web, the Mac app and the Windows app, and it retires the install that ran only on one computer.

## What's new

- The first run offers two choices, on the web and in both apps: Join a team, or Add a server. There is no "this computer only" choice.
- An install that was set up to run only on this computer keeps its data and asks you to add a server, or to join a space on someone else's, before you continue.
- The Windows app asks with the same summary the Mac app shows, including a yes that names the card. It tries Windows Hello, then the TPM, then Windows data protection. A Hello prompt on each signature has not been shown on a real PC yet, so that key is still held and the app asks in its own window first.
- An assistant can ask to enrol a Windows computer, to change how this computer runs, and to read how the apps are signed. A step that changes a device waits for your one tap. Nothing changes until you approve.

## Signing

A published Mac app is Developer ID signed and notarized only when the GitHub environment named `apple` has these secrets: APPLE_DEVELOPER_ID_P12, APPLE_DEVELOPER_ID_P12_PASSWORD, APPLE_DEVELOPER_ID_IDENTITY, APPLE_NOTARY_KEY_P8, APPLE_NOTARY_KEY_ID, APPLE_NOTARY_ISSUER. Until they are set, the dmg is ad hoc signed and you allow it once in System Settings.

A published Windows installer is Authenticode signed only when the GitHub environment named `windows` has WINDOWS_AUTHENTICODE_PFX_B64 (the certificate as base64) and WINDOWS_AUTHENTICODE_PFX_PASSWORD. Until they are set, the installer is unsigned and Windows asks you to choose More info, then Run anyway. The release prints a skip line that names each missing secret. Setting the repo variable WINDOWS_SIGNING to `required` fails a publish that is still unsigned.

The Windows install script still checks SHA256SUMS and does not check SHA256SUMS.sig. Windows PowerShell 5.1 cannot check an Ed25519 signature.

## Updating

Download the new Mac dmg or the Windows installer from the release and replace the app. Then run `vyre space up` on your server.
