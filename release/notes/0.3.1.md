Vyre 0.3.1 fixes installing Vyre as root on a fresh server, and updating a server from Settings when the update folder belongs to root.

## Fixed

- The install line now works when it is run as root, which is how most fresh servers log in. It used to stop at "VYRE_STORE is set in the environment of a root run" before starting anything.
- Updating a server as yourself, from Settings or with `vyre update`, no longer stops with a permission error on `release.swapped`.
- The server's `vyre` command passes its shell checks again.

## Updating

A Linux server updates from Settings, or with `vyre update`. The stable channel takes this release. Your data, vault and sign-ins stay as they are.
