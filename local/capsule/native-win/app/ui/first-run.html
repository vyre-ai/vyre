Vyre Lumen

Connect this computer to your Vyre.

On another device where you are signed in, open Devices, then Add a device, and type the code it shows here.

Enter your Vyre's address, like alex.vyre.run. You pair this computer there, with the long code your other device shows and three words to confirm.

If Windows said it did not recognize this app, choose More info, then Run anyway.
