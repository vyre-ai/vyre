# Vyre app

The one Expo app (ADR 0027): the web app the box serves at `/app/`, the hosted app at app.vyre.run, the Android APK and the fallback iOS build, all from this folder. Stack: Expo 54, expo-router 6, React Native Web, Reanimated, Gesture Handler, zustand.

It has its own `package.json` and `package-lock.json` and is not part of the root npm workspace.

## Commands

```sh
npm install            # in apps/app
npm run web            # dev server, stop it when done
npm run export:web     # static SPA in dist/, base path /app
npm run typecheck      # tsc --noEmit
npm test               # node --test, DOM-free tests under perf/ and src/
```

On a shared Mac, run exports through the team build lock (<team-dir>/buildlock.sh) at nice 15.

## Layout

- `app/`: routes. `(tabs)` holds Now, Chats and Agents, which stay mounted once opened.
- `src/api/client.ts`: the box client (`call(tool, input)` and `events(onEvent)`), per `apps/CONTRACT.md`.
- `src/perf/`: the frame meter from `perf/meter.js`; open the web app with `?perf=1` to feed it, then `window.__vyrePerf.report()`.
- `src/theme/tokens.ts`: generated by `npm run tokens` at the repo root from `docs/design/one-app/tokens.json`. Never edit it.
- `android/` and `ios/`: generated by `expo prebuild`, never committed.
